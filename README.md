# WanAPIs (wanapis)

Developer-focused AI API gateway with an OpenAI-compatible endpoint. One API key gives access to GPT, Claude, Gemini, DeepSeek, image, video, and audio models behind a single unified surface — with a model marketplace, usage logs, quota management, transparent metering, multi-channel routing, and failover.
